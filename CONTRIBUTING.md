# Contributing to HunzWeb-O51W

Terima kasih atas minat Anda untuk berkontribusi! 🎉

## Cara Berkontribusi

### 🐛 Melaporkan Bug

1. Cek [Issues](https://github.com/hunz/hunzweb-o51w/issues)
2. Buat issue dengan template **Bug Report**
3. Sertakan: deskripsi, langkah reproduksi, screenshot

### ✨ Mengusulkan Fitur

Buka issue dengan template **Feature Request**.

### 🔧 Pull Request

1. Fork repo & clone
2. Buat branch: `git checkout -b feat/nama-fitur`
3. Commit dengan pesan jelas
4. Push & buat PR

## Setup Development

```bash
git clone https://github.com/hunz/hunzweb-o51w.git
cd hunzweb-o51w
npm install
